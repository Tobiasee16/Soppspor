# Is the Boyce index broken, or are the models?

Generated by `scripts/check_boyce.py`. No model fitted, no real data read.

200 synthetic trials per case, at the sample size of a real fold: 50 presences against 680 background, scores drawn on the logistic scale around a low base rate so the skew matches what these models actually emit.

## The published method, against models of known quality

| case | expected | AUC | Boyce (mean +/- sd) | NaN trials |
|---|---|---|---|---|
| separable | +1 (AUC is exactly 1) | 1.000 | +nan +/- nan | 200 |
| perfect | high (this is a 0.92-AUC model, not a separating one) | 0.922 | +0.914 +/- 0.103 | 0 |
| good | clearly positive | 0.702 | +0.321 +/- 0.361 | 0 |
| random | **~0** | 0.501 | -0.417 +/- 0.332 | 0 |
| inverted | clearly negative | 0.296 | -0.733 +/- 0.160 | 0 |

**The metric fails its own sanity check, and the way it fails is the whole story.**

A model with no skill at all - presences and background drawn from the same distribution - returns **-0.417 +/- 0.332**. The correct answer is zero. The published implementation is systematically biased downward on skewed scores, so on this data a negative Boyce index is the *expected* output of a model with no signal rather than evidence of an inverted surface.

For reference the separating case returns +nan +/- nan and the 0.70-AUC case +0.321 +/- 0.361.

**This retracts an interpretation.** FINDINGS sections 7 and 8 read lightgbm's negative Boyce as the flexible model producing a surface that is 'acceptable in pairs and incoherent as a surface'. That reading is not supported. The values were largely the metric's own bias, and the same bias applies to every Boyce number reported so far. Reading 2 from FINDINGS section 8 is the one the evidence supports.

## Why: where the windows land

The published method slides an equal-width window across the *score range*. These models put nearly all their mass near zero with a thin right tail, so most windows sit in the tail. Background points per window, one representative trial of the `good` case, 101 windows in order of increasing score:

* windows holding zero background points: **1 of 101**
* windows holding fewer than 10: **39 of 101**
* the busiest window holds 324
* median occupancy 21

A window holding one or two background points produces a ratio F that is set by whether a single point happened to land there. Spearman then correlates window position against a sequence that is mostly noise, and does so over as many noisy windows as real ones.

## A candidate fix: windows on quantiles, with a minimum occupancy

Place the windows on background-score quantiles instead of on score values, and drop any window still holding fewer than 10 background points. Every surviving window then carries comparable weight. Same trials, same data:

| case | expected | published | quantile windows |
|---|---|---|---|
| separable | +1 (AUC is exactly 1) | +nan +/- nan | +nan +/- nan |
| perfect | high (this is a 0.92-AUC model, not a separating one) | +0.914 +/- 0.103 | +0.833 +/- 0.087 |
| good | clearly positive | +0.321 +/- 0.361 | +0.808 +/- 0.088 |
| random | **~0** | -0.417 +/- 0.332 | -0.006 +/- 0.298 |
| inverted | clearly negative | -0.733 +/- 0.160 | -0.798 +/- 0.098 |

The criterion for preferring one over the other was fixed before this ran and is not about our models: recover +1 for `perfect`, a clearly positive value for `good`, ~0 for `random`, clearly negative for `inverted`, with a standard deviation small enough that a single fold means something.

Quantile windows do NOT meet that criterion (+0.833 / +0.808 / -0.006 / -0.798, sd on `good` 0.088).

## What this does and does not license

Changing a metric after seeing a disappointing result is exactly the move CLAUDE.md's working agreement warns about, so the guard rails matter:

* The decision was made against synthetic data with known answers, not against any real species result.
* The criterion was written down before the comparison ran.
* Both implementations stay in the codebase and both are reported for the real runs, so the change is visible rather than substituted.
* AUC is untouched. If the two metrics disagree about a species after this, that disagreement is still a finding.
