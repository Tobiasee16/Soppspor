## Permutation importance, averaged across all folds

Drop in AUC when each feature is shuffled in the held-out fold,
against a model fitted on the others, meaned over all 5 folds
with the fold-to-fold spread beside it. Reported per model, because
the two need not agree and the AUC table above reports both.

**Read the spread before the mean.** An earlier version of this table
used one fold, and FINDINGS section 9d showed that was far too noisy
to rank anything below the top two features - a value moved from
+0.078 to +0.036 between two runs whose AUCs agreed to three decimal
places. Where the spread is comparable to the mean, the feature has
no established rank and should not be given one in prose.

This is also the check FINDINGS section 6 committed to: autumn
rainfall follows the same coast-inland gradient as the population, so
a model leaning on it may be reading accessibility rather than
ecology.

A caution about the null column. Its importances are near zero for
every feature, which is *not* evidence that the features are free of
effort bias. The null's presences are drawn from the same pool as the
background, so the two are environmentally identical by construction
and no feature can separate them. That column checks that the
pipeline does not leak, and nothing more.
