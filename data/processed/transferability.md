# Transferability - fitted on Agder, evaluated once on Kristiansand

Generated by `scripts/run_transfer.py` on 2026-09-12.

**Training extent:** Agder fylke, minus the held-out extent and everything within 4000 m of it.
**Held-out extent:** Kristiansand kommune (post-2020 merge). Never seen during fitting.

This is the question CLAUDE.md's study-area section poses: does a model
fitted regionally hold up in a smaller area it was not trained on? Every
other number in this project is Agder-internal - spatially blocked, but
trained and tested inside one region.

**It is not cross-validation.** There is one test set and one number per
model. The interval is a percentile bootstrap over the held-out points,
which covers sampling variation in those points and nothing else - in
particular it says nothing about whether Kristiansand's records are a
fair sample of Kristiansand, which on effort-biased data is the larger
worry.
