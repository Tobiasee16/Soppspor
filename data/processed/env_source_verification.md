## Traps confirmed the hard way

- **WMS axis order.** EPSG:25833 in WMS 1.3.0 is easting-first. Reversed,
  the query lands in the sea and returns "Search returned no results" -
  indistinguishable from a location with no data. We use WMS 1.1.1.
- **INFO_FORMAT.** `text/plain` returns a feature ID and *no attributes*.
  Only `application/vnd.ogc.gml` carries values.
- **SR16.** The raster layers return nothing through GetFeatureInfo. The
  vector layer `SRVVOLMB` returns the whole stack including uncertainty.
- **seNorge.** NetcdfSubset returns HTTP 503; OPeNDAP works. The Y axis
  descends, and assuming otherwise reads a cell ~1500 km away that
  returns the fill value rather than an error.
- **Elevation over water** is answered from depth contours as a negative
  height. It is a real answer to a different question.
